# Simple Task App

This repo contains a **single-file** task app in `HalalMeatOrder.html` (the filename is legacy; the contents are now a task app).

## Task framework (the fields)

Each task is captured using:

- **Who**: owner / person responsible
- **What / Why**: what to do, and why it matters
- **When / Where**: due date/time and context/location
- **How / Framework**: steps to do it + process/tool/framework used (e.g., Kanban, SMART, GTD)

## How to run

- Open `HalalMeatOrder.html` in your browser (double-click the file).

No server is required.

## Data storage

- Tasks are stored in your browser via **LocalStorage** (offline-friendly).
- Use **Export JSON** to copy tasks to clipboard and back them up.
- Use **Import JSON** to restore/merge tasks (same `id` overwrites).
