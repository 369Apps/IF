# FDE Interview Prep

A field-manual style practice kit for **Forward Deployed Engineer** interviews (Palantir FDSE, OpenAI FDE, Anthropic-style applied loops, and startup FDE roles).

Open [`FDEInterviewPrep.html`](FDEInterviewPrep.html) in a browser. Progress, drill scores, and behavioral stories save in `localStorage` on this machine.

## What is in it

| Section | What you practice |
| --- | --- |
| Loop map | Recruiter → coding gate → decomposition / case → learning → design → values |
| Decomposition | Five-move frame, worked examples, 16 timed prompts, self-grade rubric |
| Coding | Three practical problems with hidden tests (BFS, event rollup, DAG schedule) |
| Learning round | Unfamiliar mini-library + a double-count bug to find by tracing one path |
| Client | Stakeholder pushback, live-demo failure, security freeze |
| AI design | Evals-first cases (RAG, claims triage, support agent) |
| Behavioral | Story cards for failure, ambiguity, “why this company” |
| Plan | Four-week schedule with checkboxes |

Most loops fail people on **decomposition and customer judgment**, not LeetCode. Use the timer. Talk out loud.
